Google Cloud Shell Интеграция & Дублирование Терминала

Ultra-Fast Cloud Compute

Все вычисления лаборатории можно запускать в Google Cloud Shell / Cloud VM. Порты 8000 (API), 8001 (WS) автоматически пробрасываются на ваш локальный компьютер через безопасный туннель.

ШАГ 1

Быстрый запуск в Google Cloud Shell

Откройте Google Cloud Shell в браузере и вставьте одну команду:

git clone https://github.com/your-repo/finance-lab.git && cd finance-lab && bash cloud/setup-vm.sh
ШАГ 2

Подключение и зеркалирование терминала в Windows

В вашем терминале PowerShell на компьютере выполните:

powershell -ExecutionPolicy Bypass -File .\cloud\connect.ps1 -Action connect -UseCloudShell
ШАГ 3

Интерактивный Терминал (SSH Session)

Для открытия прямого интерактивного шелла с дублированием:

powershell -ExecutionPolicy Bypass -File .\cloud\connect.ps1 -Action connect -Interactive
